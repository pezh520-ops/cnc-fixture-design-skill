# 第 16 章 误区、失效模式与排查

## 核心思想
夹具失效很少是"某一个零件做错了"，而是"定位—夹紧—刚性—排屑—动作顺序"链条上的某一环被忽略。排查要按链条顺序做，不要一上来就改夹紧力。

## 方法与框架

### 排查顺序（从静到动）
1. **定位系统重复性**：同一工件、同一位置，反复装夹打表；误差大 → 定位问题。
2. **夹紧瞬间位移**：夹紧前后在同一位置打表对比；夹紧就动 → 夹紧点/支撑问题。
3. **切削中位移**：加工中用百分表监控 X/Y 方向；有位移 → 夹紧力/刚性/让刀。
4. **压力与顺序**：油缸前后装压力表，看压力是否建立；用薄铁条夹在压板与工件间，验证先动的缸是否真正夹紧。
5. **三坐标/首件**：定位/夹紧都正常但尺寸超差 → 夹具制造精度/磨损/机床/刀具。
6. **变形**：松开后测量 vs 夹紧状态测量；差异大 → 夹紧变形/内应力。

### 定位类误区
- 两个圆柱销做一面两孔：孔距误差导致装不进/别劲。
- 菱形销方向装反/可转动：角向失效。
- 辅助支承当定位：工件被顶起，定位面不贴合。
- 毛坯三点选在浇冒口/分型线：余量不均。
- 基准不重合：定位误差直接叠加。
- 过定位：夹紧后工件变形/定位漂移。

### 夹紧类误区
- 夹紧力不足：液压夹具最常见；加工中工件移动、振刀、尺寸漂移。
- 盲目加大夹紧力：薄壁件压扁，松开回弹。
- 压点悬空/不在支撑三角形内：工件弯曲、翘起。
- 压点在薄壁/外观面：压伤/变形。
- 顺序只靠油路远近：先动的缸只"动了"，未夹紧。
- 油缸弹性连接无自锁：重切削时微动。
- 转角缸压紧后移动：螺旋槽/钢球磨损、压板过重、速度过快。
- 油缸螺钉用 8.8 级：安装孔小、强度不足，应用 10.9/12.9。

### 液压/油路类误区
- 油路间距不足：加工误差串油。
- 无节流阀：轻工件被先动缸带偏；转角缸速度过快转不到位。
- 油路未清洗：铁屑进入油缸，内泄/卡死。
- 支撑缸当夹紧缸：过度受力，失去支撑精度。
- 保压无蓄能器：长时间掉压。
- 按 7 MPa 算老液压站：实际只有 5 MPa，夹紧力不足。
- 支撑缸先动压变形：顺序/压力切换不当。

### 结构/精度类误区
- 高立板用螺纹连接：刚性不足，振动。
- 夹具体不做时效/退火：长期变形。
- 无排屑/防屑：铁屑堆积、卡死、定位不准。
- 无退料机构：取件慢/工件被销咬住。
- 易损件不可换：整套报废。
- 无吊环/无动平衡：搬运/高速旋转风险。
- 公差标过严：成本高、周期长。
- 未考虑阳极/热处理后尺寸变化：装不进/定位松。
- 三坐标合格但重复装夹超差：定位/夹紧重复性没验证。

### 薄壁类误区
- 硬爪直接夹：点接触、压陷。
- 径向夹紧薄壁套：应改轴向/面接触。
- 卡尺用力压测：测量本身变形（案例 0.06 mm）。
- 无辅助支撑：悬空振刀。
- 一次装夹完成所有面：夹紧变形未释放。
- 多点但受力不均：仍局部变形；需要浮动/均衡。

### 管理/流程类误区
- 信息不全就开工：机床接口/行程/载重/油路未确认。
- 方案图删旧版：客户改回初版无据。
- 不做运动/刀具干涉推演：现场撞刀。
- 现场让操作工调顺序阀/增压器：动作/夹紧力失控。
- 未确认液压站实际压力/流量。
- 未做防错：工件装反/装不到位。

## 关键概念
- **重复定位精度**：多次装夹的位置一致性。
- **夹紧变形**：夹紧力引起的弹性变形。
- **让刀**：切削力导致刀具/工件偏移。
- **串油**：油路之间因壁厚不足/加工误差连通。
- **防错（Poka-yoke）**：通过结构/气密/视觉防止装反/装偏。

## 快速诊断表
| 现象 | 优先排查 | 次选 |
|---|---|---|
| 装不进/别劲 | 过定位、两圆柱销、菱形销方向 | 销孔配合、毛坯余量 |
| 加工中工件移动 | 夹紧力不足、顺序不对、无自锁 | 压点悬空、支撑不足 |
| 尺寸漂移 | 定位重复性、刀具磨损、热变形 | 夹具磨损、机床精度 |
| 振刀/振纹 | 夹紧力不足、悬伸过长、支撑不足 | 刀具锋利度、机床刚性 |
| 薄壁圆度超差 | 夹紧变形、硬爪、径向夹紧 | 内应力、端面垂直度 |
| 孔位置度超差 | 角向定位、钻套间隙、分度误差 | 基准不重合、夹具磨损 |
| 铁屑卡死 | 防屑/排屑结构 | 吹屑、清洗 |
| 油缸不动作/慢 | 油路堵塞、节流、压力不足 | 密封内泄、顺序阀 |
| 保压掉压 | 蓄能器、内泄、密封 | 油路接头 |
| 焊后变形/虚焊 | 夹紧力过大、焊点分流、无保护块 | 焊接顺序、定位基准 |

## 设计规则
- 当出现尺寸问题时，先验证定位重复性，再验证夹紧位移，最后才怀疑机床/刀具；因为定位/夹紧是夹具可控项。
- 当薄壁件超差时，先松开测量，判断是夹紧变形还是内应力；再决定改夹具还是改工艺。
- 当怀疑顺序时，在油缸前后装压力表/夹铁条验证；不要凭感觉。
- 当液压站老旧时，按 5 MPa 而不是 7 MPa 计算夹紧力；因为实际压力往往达不到额定值。
- 当外观面压伤时，改软材料/减小接触面积/增加让位；不要靠降低夹紧力硬撑。
- 当自动化频繁故障时，先查吹屑/气密/夹紧检测三件套；这是最常见的根因。

## 工作示例（凸轮夹具角向不稳）
1. 现象：内涨芯轴定 Φ65 孔、Φ12 孔角向，角向一致性差。
2. 排查：定位面/定位孔垂直度 → 角向销在 Y 向移动 → 直线导轨刚性不足、销悬伸过长。
3. 改进：角向销只在与内孔连线方向浮动（X 向），Y 向由硬轨 T 型槽限制；销子留余量，装配后精铣两销；增加三点浮动支撑；压板改为动向点压。
4. 效果：进给提高 30% 不移动；角向一致性改善。
5. 启示：角向定位销不仅要"定位"，还要能"抵抗切削扭矩"；只定位不抗扭的销是"假销"。

## 关键要点
1. 排查顺序：定位重复性→夹紧位移→切削位移→压力/顺序→三坐标→变形。
2. 夹紧力不足是液压夹具头号风险；盲目加大是薄壁件头号风险。
3. 顺序靠阀不靠油路远近；压力表/铁条是最简单的验证工具。
4. 薄壁件先区分夹紧变形与内应力，再改方案。
5. 自动化先查吹屑/气密/夹紧检测。
